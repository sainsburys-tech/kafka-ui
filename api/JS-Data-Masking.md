## Getting Started
This feature decouples legacy kafbat masking as well as rbac config from internal config manager into a standalone real-time, no downtime data masking as well as unmasking capabilities.

using localstack aws:

create masking table
```sh
aws dynamodb create-table --table-name sainsburys-kafbat-masking --attribute-definitions AttributeName=partitionKey,AttributeType=S --key-schema AttributeName=partitionKey,KeyType=HASH     --provisioned-throughput ReadCapacityUnits=5,WriteCapacityUnits=5 --endpoint-url http://localhost:4566

```

create rbac table
```sh
aws dynamodb create-table --table-name sainsburys-kafbat-rbac --attribute-definitions AttributeName=partitionKey,AttributeType=S --key-schema AttributeName=partitionKey,KeyType=HASH     --provisioned-throughput ReadCapacityUnits=5,WriteCapacityUnits=5 --endpoint-url http://localhost:4566

```

## Data Masking
The below classes are introduced to handle autonomous data masking based on tagging in Confluent Data Governance API:
- **DynamoDbConfig** - Manages service database connection to DynamoDb.
- **DynamoClusterProperties** - Retrieves all dynamoDb config for both rbac and masking table and handles mapping to Kafbat DTOs.
- **ConfluentApiClient** - Handles API calls to Confluent API using openFeign client.
- **MaskingUpdateSchedule** - Hourly scheduled cron that retrieves latest masking rules from logical kafka clusters and topics to internal sainsburys-kafbat-masking dynamodb table.

## Data Unmasking API
The below classes are introduced to handle data unmasking requests from Kafbat UI - **Data Unmasking Form**:
- **unmasking.tsp** - This is a contract-typespec definition for data unmasking api interface.
- **UnmaskingController** - RestController implements UnmaskingApi generated by internal OpenAPI generator based on the **unmasking.tsp** definition.
- **UnmaskingService** - Handles business logic to add data unmasking role for requesting kafbat user and log **ServiceNow** audit ticket.
- **ServiceNowClient** - Handles API calls to [ServiceNow Generic Inbound API](https://sainsburys-tech.atlassian.net/wiki/x/SADjCQ) 
- **ServiceNowAuthConfig** - ServiceNow authentication interceptor to set authentication for ServiceNow API calls.

The below classes were updated to process the unmasking workflow:
- **DataMasking** - Add rbac check if kafbat user has data unmasking role for data mask deserializer.
- **DeserializationService** - Validates deserializer to apply for kafbat user based on **DataMasking** check.
- **MessagesController** - Pass login principal to service to determine roles and deserializer on **MessagesService**.
- **MessagesService** - Retrieves kafka topic messages and applies deserializer received from **DeserializationService**.
- **main.tsp** - Add new **unmasking.tsp** to execute OpenAPI generator
